# 온보딩 시나리오 (검토용 초안 2차)

> 일반적인 덱빌딩 게임과 같은 내용(적 체력, 적의 행동 예고, 방어도, 묘지, 드로우 등)은 빼고
> **우리 게임에서만 다른 것**만 안내합니다. 전투 5단계 + 보상 4단계 = 총 9단계.
>
> 구현할 때 아래 **「제목」/「본문」** 문구는 `Assets/Resources/SpellData/onboarding.json`으로 옮겨
> 단계 ID(`B1` 등)를 키로 불러오게 만듭니다. 이후에는 JSON만 고치면 게임 문구가 바뀝니다.

## 공통 규칙

| 항목 | 내용 |
|---|---|
| 노출 | 첫 실행 1회. 완료/건너뛰기 시 저장되어 다시 나오지 않음. 일시정지 메뉴의 「튜토리얼 다시 보기」로 다음 새 게임에 다시 켬 |
| 유도 방식 | 단계별 강제. 현재 단계의 강조 영역만 밝고 조작 가능, 나머지는 어둡게 가리고 막음 |
| 진행 | `[확인]` 단계는 팝업의 확인 버튼으로, `[행동]` 단계는 지정 행동을 해야 다음으로 넘어감 |
| 손 안내 | `[행동]` 단계에서 3초간 입력이 없으면 손가락 고스트가 드래그/클릭 동작을 반복 시연 |
| 건너뛰기 | 모든 팝업 우측 위에 「건너뛰기」 → 확인 창 → 온보딩 전체 종료 |

### 고정 데이터 (구현 완료 · 온보딩 판에서만 적용)

- **첫 손패 (뽑는 순서)**: 정사각형 · 반 칸 삼각형 · 정사각형 · 반 칸 삼각형 · 평행사변형
  - 정사각형 + 반 칸 삼각형 → **불씨** 완성 / 정사각형 → **방벽** 완성
  - 반 칸 삼각형 → 도안에 남겨 **고정** 체험 / 평행사변형 → 손패에 남겨 **버려짐** 체험
- **2턴 손패**: 무작위
- **첫 조각 보상**: 1번 카드 = 씰링만 1개, 2번 카드 = 코팅만 1개, 3번 카드 = 무작위
- **고정 조각 표시**: 이전 턴에 놓은 조각은 어둡고 탁해지고, 윗면에 금속 핀이 박힘
- 온보딩을 끝냈거나 건너뛴 뒤의 새 게임은 손패·보상 모두 기존처럼 무작위

## 1부. 첫 전투

### B1 · 도안 채우기 `[행동]`
- 강조: 손패의 정사각형·반 칸 삼각형, 불씨 도안
- 허용: 두 조각을 불씨에 놓기 (들고 있는 동안 회전 가능)
- 완료: 불씨 완성
- **제목**: 도안 채우기
- **본문**:
  > 조각으로 도안의 빈 곳을 빈틈없이 채우면 그 주문을 쓸 수 있습니다.
  > 정사각형과 반 칸 삼각형을 끌어다 불씨 도안을 채우세요. (R 키·우클릭: 회전)

### B2 · 대상 주문 시전 `[행동]`
- 강조: 불씨의 「시전」 버튼, 적
- 허용: 시전 버튼 클릭 후 적 클릭, 시전 버튼에서 적에게 드래그
- 완료: 불씨 시전
- **제목**: 주문 시전
- **본문**:
  > 불씨는 적 하나를 골라 공격합니다.
  > 시전 버튼을 누른 뒤 적을 클릭하거나, 시전 버튼을 적에게 끌어다 놓으세요.

### B3 · 즉시 시전 `[행동]`
- 강조: 손패의 정사각형, 방벽 도안과 「시전」 버튼
- 허용: 정사각형을 방벽에 놓기 → 시전 버튼 클릭
- 완료: 방벽 시전
- **제목**: 바로 시전되는 주문
- **본문**:
  > 방벽처럼 대상이 없는 주문은 시전 버튼을 누르면 바로 발동합니다.
  > 정사각형으로 방벽을 채우고 시전하세요.

### B4 · 턴 종료 `[행동]`
- 강조: 손패의 반 칸 삼각형, 불씨 도안, 「턴 종료」 버튼
- 허용: 반 칸 삼각형을 불씨에 놓기 → 턴 종료 (조각을 놓기 전에는 턴 종료 버튼을 막음)
- 완료: 2턴 시작
- **제목**: 턴이 끝나면
- **본문**:
  > 남은 반 칸 삼각형을 불씨에 놓고 턴을 종료하세요.
  > · 도안에 놓인 조각은 **고정**되어 다음 턴에도 남습니다.
  > · 손패에 남은 조각은 **버린 더미**로 갑니다.

### B5 · 고정된 조각 `[확인]` (2턴 시작)
- 강조: 불씨 위의 핀 박힌 반 칸 삼각형, 불씨 이름표의 「···」 버튼
- **제목**: 고정된 조각
- **본문**:
  > 핀이 박힌 조각은 이전 턴에 놓은 고정 조각이라 옮길 수 없습니다.
  > 치우려면 「···」 → 「도안 비우기」를 누르세요. 고정 조각은 버린 더미로 갑니다.

→ 이후 첫 전투는 자유 플레이.

## 2부. 첫 스테이지 클리어 — 보상

### R1 · 도안 시험 배치 `[행동]`
- 강조: 도안 보상 카드 3장, 내 격자
- 허용: 카드를 내 격자에 드래그 (카드 클릭 시 빈 곳에 자동 배치)
- 완료: 보상 도안이 시험 배치됨
- **제목**: 도안 놓아 보기
- **본문**:
  > 보상은 받기 전에 미리 놓아 볼 수 있습니다.
  > 마음에 드는 도안을 끌어다 내 격자에 놓아 보세요.

### R2 · 보관함과 결정 `[행동]`
- 강조: 보관함, 「결정」 버튼
- 허용: 도안 이동(격자↔보관함)·회전, 결정
- 완료: 도안 획득 → 조각 보상 탭으로 전환
- **제목**: 보관함
- **본문**:
  > 내 격자에 놓인 도안만 전투에 나옵니다. 지금 안 쓸 도안은 보관함에 넣어 두세요.
  > 위치를 정했으면 결정을 누르세요.

### R3 · 씰링과 코팅 `[확인]`
- 강조: 1번 카드(씰링 조각), 2번 카드(코팅 조각)
- **제목**: 씰링과 코팅
- **본문**:
  > **씰링**: 조각의 1/4 구역에 박는 동그라미. 구역마다 하나씩, 한 조각에 **여러 개** 붙일 수 있습니다.
  > 그 조각으로 시전하면 붙은 씰링 효과가 모두 발동합니다.
  > **코팅**: 조각 전체에 입히는 재질. 한 조각에 **하나만** 입힐 수 있습니다.
  > 그 조각이 들어간 주문이 강해집니다.
  > 카드에 마우스를 올리면 자세한 효과를 볼 수 있습니다.

### R4 · 조각 시험 배치와 결정 `[행동]`
- 강조: 조각 보상 카드 3장, 내 격자, 「결정」 버튼
- 허용: 카드를 내 격자 어디에나 드래그 (손을 떼도 유지, R 회전) → 결정
- 완료: 조각이 덱에 추가 → 온보딩 완료 저장
- **제목**: 조각 놓아 보기
- **본문**:
  > 조각도 내 격자 어디에나 놓아 보며 도안에 맞는지 확인할 수 있습니다.
  > 고른 뒤 결정을 누르면 덱에 들어갑니다.

## 1차 초안에서 뺀 내용

- 전투 시작·승리 조건 설명, 도안이 무엇인지 따로 보여 주는 단계 → B1에 합침
- 시전 결과(피해 수치·묘지) 설명
- 적의 행동 예고·방어도 설명
- 2턴 시작 시 받은 피해·드로우 결과 설명
- 전투 안내 마무리, 보상 화면 소개, 버리기 칸 설명
- 씰링·코팅을 따로 나눈 두 단계 → R3 하나로 합침
